## Security Findings

| Severity | Location | Issue | Status | Remediation |
|---|---|---|---|---|
| Medium | `web/src/components/widgets/FineTuningWidget.tsx:248` (`JsonPreview`) | DOM XSS sink: user-editable SFT/RLHF/DPO text is `JSON.stringify`-ed, wrapped in `<span>` by regex, then written through `dangerouslySetInnerHTML`. `JSON.stringify` does not escape `<`/`>`/`&`, so typing `<img src=x onerror=…>` into a textarea is parsed as live markup. Reachability: **self-XSS only** — state is component-local, never persisted or reflected to another user/URL, and the site is a static export, so no cross-user vector. | fixed | HTML-escape `&`, `<`, `>` immediately after `JSON.stringify` and before the highlight regex. Highlighting and normal display are unchanged; special characters now render literally. Verified with a Node reproduction (raw `<img` present before, absent after). |
| Low | `internal/workspace/workspace.go:118` | Bundled asset extraction uses a predictable path (`os.TempDir()/data-in-ai-revolution-go-bundle`) with `os.RemoveAll` + `MkdirAll` before writing. On a shared host another user could race/pre-create the path (TOCTOU / symlink). Local-only tool, no privilege boundary crossed. | documented | Prefer `os.MkdirTemp` with `0700`, or stat an existing path and refuse if it is not owned by the current user. Requires a behavior change (cache reuse vs. fresh extract), so left for a design decision. |
| Low | `.github/workflows/deploy.yml:21,23,41,54` | GitHub Actions referenced by mutable tags (`actions/checkout@v4`, `setup-node@v4`, `upload-pages-artifact@v3`, `deploy-pages@v4`) rather than commit SHAs. Supply-chain hardening only. | documented | Pin each action to a full commit SHA; use Dependabot to bump. |
| Low | `internal/catalog/catalog.go:194,250,278` | `strings.Title` is deprecated (Go 1.18+) and has poor Unicode word-boundary handling. Cosmetic titles only, no injection. | documented | Replace with `cases.Title(language.Und)` from `golang.org/x/text`. |
| Low | `internal/catalog/catalog.go:380` | `regexp.MustCompile(`[^a-z0-9]+`)` runs on every `slugify` call instead of once at package scope. | documented | Hoist to a package-level `var`. |

**Checked and clean:** no `eval`/`exec`/`pickle`/`yaml.load` in first-party code; no `shell=True`; all subprocess/`exec.Command` calls use argument lists (no shell interpolation); no `verify=False`, no `allow_origins=["*"]`, no `0.0.0.0` binds, no auth/CORS surface (static site + local CLIs); no `md5`/`sha1` for credentials; no SSRF/network egress beyond `git`/`python3 --version` probes; no LLM tool-calling code, so prompt-injection/tool-use hazards do not apply.

## Deslop Applied

- `web/src/app/page.tsx:157` — removed unused destructured bindings `label` and `i` from the TOC `SECTIONS.map(({ id, num }) => …)`. Neither was referenced; the callback still renders `num` and `getSectionDescription(id)`. Behavior-preserving; clears the two `@typescript-eslint/no-unused-vars` warnings.
- `internal/tui/app.go:37,54` — removed the write-only `browserState.searchPlaceholder` field and its constructor assignment. The value was already consumed by `input.Placeholder` two lines earlier and never read again; no behavior change.
- `scripts/manim_aggregation.py:6-10` and `src/data_in_ai_revolution/assets/scripts/manim_aggregation.py:6-10` — removed a commented-out triple-quoted `names = [...]` stub that duplicates (and contradicts, being an 11-name version of a ~2500-name list) the real `from names import names` import. Both copies kept byte-identical.

### Deliberately not changed (noted instead)

- `internal/launch/launch.go:66` `AbsolutePath` and `internal/catalog/catalog.go:41` `Metadata` / `:28-30` `CommandSpec.Label` are unread exported symbols. Left in place to avoid removing API surface.
- `internal/tui/app.go:207,211` `Model.snapshot` is stored but never read. Removing it would change the exported `NewModel(root, snapshot bool)` signature (used by tests), so it is documented rather than deleted.
- Duplicated Go/Python catalog + doctor implementations are intentional (primary Go tool vs. legacy Python fallback) and were not touched.

## Full Review Findings

Ranked by impact (read-only; no code changes made in this phase).

1. **DOM XSS in the fine-tuning JSON preview — `FineTuningWidget.tsx:248`.** The one genuinely exploitable sink found. Fixed above; reachability is self-only.
2. **Untested process-spawning and temp-extraction paths — `internal/launch` and `internal/workspace` report `[no test files]`.** `launch.Start` spawns `python3`/`jupyter`, and `workspace.EnsureBundledRoot` writes to a shared temp dir. These are the riskiest Go units and have no coverage. Recommend table tests with an injected launcher plus a temp-root test.
3. **No automated front-end tests — `web/package.json` has no `test` script.** ~7k LOC across 9 interactive widgets are covered only by `tsc`/`eslint`; the XSS above would not have been caught. Recommend Vitest + React Testing Library for widget state/handlers.
4. **Predictable temp extraction path — `internal/workspace/workspace.go:118`.** See Security Findings (Low, documented).
5. **Deprecated `strings.Title` — `internal/catalog/catalog.go:194,250,278.** Also an inconsistency: the Python fallback title-cases differently, so catalog titles can differ between implementations.
6. **Regex compiled per call — `internal/catalog/catalog.go:380.** Trivial but avoidable allocation on a hot-ish path.
7. **Duplicated logic across Go and Python tiers.** `catalog`/`doctor`/`launchers` are maintained twice; parsing rules already differ (e.g., script summary text, title casing). The Python tier is described as a migration fallback — consider deleting it or generating shared fixtures.
8. **`go test ./...` scans `web/node_modules`.** Go picks up `web/node_modules/flatted/golang/pkg/flatted` as a package. Harmless but adds noise and links a dependency's Go code into `./...`; a `go.work`/build constraint or `node_modules` exclusion would tighten it.
9. **Workflow actions not SHA-pinned — `.github/workflows/deploy.yml.** See Security Findings (Low).
10. **`install.sh` advertises `curl … | bash` with no checksum.** Inherent to the pattern; documented rather than changed.
11. **Custom font loaded via `layout.tsx` triggers `@next/next/no-page-custom-font`.** Cosmetic; migrate to `next/font`.
12. **`NewModel`'s `snapshot` flag and `launch.AbsolutePath` are dead.** Documented above.

Dependency hygiene: `uv.lock`, `go.sum`, and `web/package-lock.json` are all tracked; Go module graph is small and pinned in `go.sum`; Next/React are pinned to exact versions. No vulnerability scanner (`govulncheck`, `npm audit`, `uv pip check`) was run as part of this audit — dependency CVE status is unverified.

## Remaining Risks

- **Self-XSS residual:** the fine-tuning preview is now escaped, but `dangerouslySetInnerHTML` remains in the component. Any future change that post-processes `highlighted` before injection could reintroduce the sink; a vitest case asserting no raw `<`/`>` in the output would lock the fix. The same class of risk would not be caught by `tsc`/`eslint`.
- **Untested risky units:** `internal/launch` and `internal/workspace` have no tests; the temp-dir extraction race (Low) is therefore unverified in practice. No integration test exercises `launch.Start` against a real subprocess.
- **No vulnerability scan:** `govulncheck`, `npm audit`, and `uv pip check` were not run; dependency CVE status is unverified by this audit.
- **Documented-but-unfixed items** remain: predictable temp path, non-SHA-pinned workflow actions, deprecated `strings.Title`, per-call regex compilation, dead `AbsolutePath`/`snapshot`/`Metadata`/`Label`, and inconsistent Go-vs-Python catalog titles.
- **Bundled asset duplication:** `src/data_in_ai_revolution/assets/scripts/*` mirrors `scripts/*` with no automated sync check; drift must be caught manually (both copies were kept identical here).
- The audit branch has not been pushed and no PR was opened (out of scope).
